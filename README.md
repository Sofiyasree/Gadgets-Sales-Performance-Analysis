Gadgets Sales Performance Analysis – Power BI Dashboard

This project analyzes gadget sales across multiple countries and weekly periods using Power BI and Python.
The dashboard highlights product performance, revenue patterns, marketing impact, and customer insights.

🚀 Project Highlights
Cleaned and prepared a 500+ row dataset using Python
Built a multi-page Power BI dashboard
Identified top revenue-generating products
Analyzed weekly sales trends and customer behavior
Explored country-wise sales performance
Measured the impact of marketing spend on units sold

📈 Key Insights
✔ Earbuds generated the highest revenue: ₹87,67,47,81
✔ Bluetooth Speaker recorded the lowest revenue
✔ Portable gadgets (Earbuds, Mouse, Tablet) showed the strongest demand
✔ Higher marketing spend increased units sold (positive correlation)
✔ Sales from Japan, UK, USA, India indicate strong global reach
